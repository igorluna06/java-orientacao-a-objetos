# Java com Orientação a Objetos

Repositório criado para acompanhar meus estudos de **Java e Programação Orientada a Objetos**, utilizando como base o livro *Java com Orientação a Objetos*.

Aqui serão armazenados os exemplos, exercícios e aplicações desenvolvidos ao longo dos estudos, com o objetivo de colocar em prática os conceitos aprendidos.

## 📚 Conteúdos

- Fundamentos de Java
- Classes e objetos
- Atributos e métodos
- Construtores
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Exceções
- Coleções
- Outros conceitos de Programação Orientada a Objetos

## 🎯 Objetivo

Praticar Java através da implementação dos conceitos apresentados no livro, desenvolvendo uma base sólida em **Programação Orientada a Objetos**.
